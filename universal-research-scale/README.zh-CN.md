# Universal Research Scale（URS）中文说明

## 1. 项目定位

URS（Universal Research Scale，通用科研尺度）是一套面向科研任务的循证决策与质量控制标准。它不是简单的“科研 Prompt”，也不是要求模型机械执行用户最初指定的方法，而是要求模型先理解科研问题、研究设计与数据结构，再检索近期高质量证据与当前权威规范，比较多个候选方法，做出明确决策，执行任务，并进行独立质控。

URS 适用于医学、生物学、药学、生物信息学、化学、材料、工程、人工智能、统计学、心理学、教育学、经济学与社会科学等领域。

## 2. 核心原则

### 2.1 先查、再懂、再比、再判、再做、再审

任何具有科学后果的任务，默认遵循：

`任务诊断 → 科学问题识别 → 近5年证据检索 → 当前规范核对 → 候选方案生成 → Hard Gate → 比较与选择 → 执行 → 溯源 → QC`

### 2.2 近5年证据优先，但不是机械排除旧文献

默认优先检索当前日期向前滚动5年的高质量、高相关研究；同时保留仍有效的权威指南、统计方法、经典标准和奠基性研究。

### 2.3 相关性和方法学优先于期刊名气

URS 不把“顶刊常用”自动等同于“当前最正确”。真正排序是：

`相关性 → 方法学有效性 → 研究/数据相似度 → 权威标准 → 证据质量 → 期刊影响力 → 新近程度`

### 2.4 不能只给选项，要做决策

对重要科研任务，应明确输出：

- PRIMARY RECOMMENDATION
- ACCEPTABLE ALTERNATIVE（必要时）
- REJECTED OPTION（必要时）

### 2.5 Hard Gate 高于评分和美观

一旦出现严重科学错误、统计错误、错误分析单位、伪重复、数据泄漏、无依据排除、伪造引用、图像篡改或科研诚信问题，直接拒绝该方案。

## 3. Figure 与 Table

URS 要求 Figure 和 Table 竞争。图适合展示模式、分布、关系、轨迹、结构与对比；表适合展示精确数字、回归系数、详细分类和补充结果。

小样本连续数据默认优先考虑展示 individual observations；配对数据必须保留配对结构；纵向数据应保留重复测量结构；剂量反应应优先考虑真正的 dose-response 表达；组学图不能机械执行 PCA + volcano + heatmap 三件套。

## 4. 统计分析

统计路线必须是：

`科学问题 → 研究设计 → Estimand → 数据结构 → 模型`

禁止机械地“两组=t-test、三组=ANOVA”。必须识别分析单位、独立性、配对、重复测量、层级结构、技术/生物学重复、缺失值、异常值、混杂、多重比较和模型假设。

优先报告 effect estimate + uncertainty，而不是只有 P 值。

## 5. 写作与 Claim Ceiling

论文语言强度不得超过证据强度。重要结论可以分为：

- L0 描述
- L1 关联
- L2 预测
- L3 机制支持
- L4 因果

研究设计决定 Claim Ceiling。小 P 值不能把 L1 自动升级为 L4。

## 6. 引用与证据完整性

禁止虚构作者、题目、期刊、DOI、PMID、影响因子、分区、指南版本。每条重要引用都要问：

**这篇文献真的支持这句话吗？**

不能验证时应标记：`NOT VERIFIED`。

## 7. 可复现性与溯源

正式研究应尽量保持：

`RAW DATA → CLEANING → DERIVED DATA → ANALYSIS → RESULT OBJECT → FIGURE/TABLE → MANUSCRIPT CLAIM`

记录软件、版本、包、参数、随机种子、筛选规则、排除标准、代码、日志和环境。

## 8. 执行深度

- QUICK：格式或低风险任务
- STANDARD：普通科研分析、制图、论文段落
- DEEP：主要分析、投稿级 Figure、完整论文、严格审稿、投稿决策、研究设计

用户提出“深度思考”“严格”“投稿级”“最大严谨度”时，自动进入 DEEP。

## 9. 最终原则

**科学有效性优先于审美。方法学有效性优先于流行。证据优先于模型自信。科研诚信优先于发表便利。**
